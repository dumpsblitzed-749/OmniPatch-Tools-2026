OmniPatch is a Windows desktop application. It is currently supported on Windows 10 and Windows 11.

### How often are updates released?

Updates are released periodically to maintain compatibility with new versions of the supported AI applications. There is no fixed schedule, but the tool aims for prompt updates after major app changes.

### Will this affect my account or data?

The activation is performed locally on your machine and modifies the application client. It does not interact with or alter your cloud account data, chat history, or subscription status on the provider's servers.

### Do I need an internet connection to run OmniPatch?

An internet connection is required during the initial download of the patcher. The activation process itself is performed offline on your local system.

### What should I do if an application stops working after an update?

New versions of the AI applications may require an update to OmniPatch. Please check for the latest version of OmniPatch and re-run the activation process.

### Can OmniPatch be used on multiple computers?

Yes, OmniPatch can be installed and run on any compatible Windows PC. The activation is applied per machine.
